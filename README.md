# gg_pywords_game
파이썬 워드 게임

## 1. 프로그램 흐름
 1. 프로그램 실행 시 전체 단어 리스트를 사용자에게 제시
 2. 사용자에게 '엔터' 입력 지시 후 대기
 3. 입력 되었다면 5개의 단어를 순차적으로 사용자에게 제시
 4. 제시 된 단어와 사용자가 입력한 단어가 일치한다면 정답, 아닐 경우 오답
 5. 정답이 3개 이상일 경우 합격, 이하일 경우 불합격

## 2. 설치한 모듈
 1. pygame
 2. libpulse0     -- 사운드가 정상 출력되지 않아 추가 설치했습니다

## 3. 사용 모듈
 1. pygame
 2. os         -- libpulse0 호출용
 3. random     -- 단어 문제 제시용
 4. time       -- 게임 경과시간 확인용

## 4. 추가 기능
 문제 pdf 문서의 7번에 있는 게임 결과를 csv 파일에 누적 시키는 기능을 추가했습니다

## 5. 업그레이드
 단어 제시 후 1.5초 이후 사라지는 모드를 추가 했습니다. wordgame_upgrade.py로 실행할 수 있습니다
 사라지는 시간은 변수로 저장해놓아 변경 가능합니다
 csv 파일에 하드모드 플레이 기록으로 표시 됩니다
